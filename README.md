## Formulaire de contact

Le formulaire envoie directement les demandes à Web3Forms, sans serveur SMTP. L'adresse destinataire se configure dans Web3Forms ; la clé d'accès utilisée dans le formulaire est publique. Web3Forms applique un filtre antispam côté serveur et le formulaire inclut son champ piège `botcheck`. Lancer `npm run dev` pour le développement et `npm run build` pour préparer le site statique.
